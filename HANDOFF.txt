WHAT IS ACTUALLY WORKING
- Portable offline studio CLI: doctor, capabilities, v1 schema, plan validation,
  measured-word caption grouping, and basic brief refine/answer.
- Owner-scoped project editing with revision-conditional draft saves and candidate
  acceptance. Invalid plan issues persist. Code Lab Python traces run in a browser
  worker. Authored v1 storyboard JSON can be imported.
- Two-creator browser journey at desktop and 390 px: sign-in, create/rename/save
  project, import/approve storyboard, open private HTML preview, foreign-owner denial.
- Configured owner can create and revoke email-bound, seven-day invitation links;
  invited recipient can join. Join/replay/revocation and simultaneous redemption
  are exercised in an isolated browser test.
- Approved storyboard and preview job are enqueued transactionally. A separate
  worker claims preview jobs with renewable fenced leases and recovers expired
  claims. Creators can cancel/retry preview jobs. The preview is silent HTML with
  estimated timing, correctly labeled preview. HTML alone is never called a
  finished MP4, and public sharing remains disabled.
- Basic project Brief Builder in web and offline CLI: preserves raw request and
  exact script, offers three directions, saves revision-bound answers, and
  approves an immutable version with a frozen task-prompt bundle. Repeated approval
  returns the existing version. This does not yet research or drive production.
